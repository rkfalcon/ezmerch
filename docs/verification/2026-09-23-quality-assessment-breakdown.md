# Per-product quality assessment details

Admin review cards now summarize failed checks and show an expandable mapped breakdown of all configurable settings. Each check stores a measured value or explicit missing/inapplicable state, recorded threshold, result, explanation and setting key. Links target the corresponding input on Artwork quality. Current values are fetched independently and displayed separately from historical thresholds.

Assessment snapshots are added without changing approval decisions. Reports persist the full placement policy snapshot; comparison results persist their own policy snapshot. Source transparency now records measured partial percentage, alpha boundaries and capped edge-distance metrics. Missing older comparison snapshots force reanalysis on subsequent upload instead of being represented as current.

Legacy reports show only recorded resolution, computed lettering size from recorded geometry and saved visual reasons. Unrecorded lettering thresholds are explicitly unknown; current values never explain past decisions. Existing held products are not reapproved or regenerated by this UI change.

Validation: targeted tests cover the exact 0.9144 mm versus 2.032 mm case, snapshot immutability, all 22 settings mapping, continued non-applicable/unknown labeling and historical threshold preservation. TypeScript and scoped ESLint passed. Live authenticated browser check verified the Mazellist review card and printTextMm anchor. Temporary test account/session removed. Production alias verified. No approvals, threshold changes or purchases made.
